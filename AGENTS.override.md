- This is the only video-studio root. Keep each video in a separate `projects/<slug>` and preserve its assigned project slug.
- Before changing an Agentcut project, read the generated `AGENTS.md` and `.agents/skills/agentcut/SKILL.md`; Agentcut owns and rewrites both files.
- Preserve originals, project state, unaccepted renders and approved outputs. Never bulk-clean unknown files.
- Do not use paid services, upload private media, or publish externally without explicit user direction.
- If the user asks for video research, code-only tooling, or explicitly opts out, follow the normal Codex workflow instead.
