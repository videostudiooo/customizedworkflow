# Source and B-roll handling

## Source inspection

Use real media facts before placing a clip:

- duration and frame count at the project rate;
- displayed dimensions and rotation;
- variable or constant frame rate;
- codec and pixel format;
- audio streams, sample rate and channel layout;
- HDR or transparency risks;
- source rights and provenance.

Use `agentcut_media_info` for project assets. Use contact sheets and representative frames for visual selection. Never infer content solely from a filename.

## Shot selection

Select by editorial function:

- orientation and context;
- evidence of an action or result;
- reaction or emotion;
- contrast with the previous shot;
- transition into the next idea.

Mark unusable footage explicitly: focus, exposure, unstable camera, bad audio, missing setup, watermark, stale UI or rights conflict.

## B-roll

Use Agentcut's library first when it fits.

For external B-roll:

- prefer the user's own asset, then an authoritative primary source;
- retain canonical URL, creator, title, date, access date, rights note and source interval;
- match the narration's meaning rather than its nearest noun;
- place the cut shortly after the anchor word when speech drives the edit;
- strip source audio unless deliberately included;
- do not present a synthetic asset as factual evidence;
- do not redistribute unused source media.

Write approved choices to the project notes before rendering.
