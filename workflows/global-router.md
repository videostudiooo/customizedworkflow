## AI Video Studio

- When the requested result is to create, edit, restructure, caption, score, voice, storyboard, preview, quality-check, render, or deliver an actual video, use `$ai-video-studio` first.
- Do not use this workflow for video-industry research, general technical questions, metadata-only questions, code-only video tooling, or when the user explicitly opts out.
- The only video workspace is `F:\AI-Video-Studio`; never create a second studio root from the current directory.
- Keep one video in one `projects/<slug>` and pass that project explicitly through the workflow.
