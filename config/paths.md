# Agentcut 本地路径约定

- 工作区：`F:\AI-Video-Studio`
- 便携 Node：`F:\AI-Video-Studio\software\node`
- npm/npx 缓存：`F:\AI-Video-Studio\cache\npm`
- Agentcut 工具：`F:\AI-Video-Studio\tools\agentcut`
- 模型缓存：`F:\AI-Video-Studio\cache\models`
- 临时帧：`F:\AI-Video-Studio\renders_temp\agentcut-frames`
- helper 日志：`F:\AI-Video-Studio\logs\agentcut\agentcut-mcp.log`
- 进程临时目录：`F:\AI-Video-Studio\cache\temp`
- Agentcut 代理缓存：`F:\AI-Video-Studio\.agentcut\proxies`
- Agentcut 临时渲染区：`F:\AI-Video-Studio\.agentcut\render`

本地 Studio 入口：`F:\AI-Video-Studio\config\agentcut-local-studio.ps1`

Helper 入口：`F:\AI-Video-Studio\config\agentcut-launch.ps1`

默认浏览器地址：`http://localhost:3000/studio`

该脚本只修改当前 PowerShell 进程的环境变量，不修改 Windows 系统级环境变量。
